2. 보조 함수 - 날짜 -> TIME_MONTH 키 만들기
```
function getMonthId($conn, $dateStr) {
    if(!$dateStr) return null;             // 날짜가 비어있으면 null 리턴

    // 'YYYY-MM' 형태를 '-' 기준으로 잘라서 연도/월 숫자 추출
    $parts = explode('-', $dateStr);
    $y = (int)$parts[0];
    $m = (int)$parts[1];

    // 1) 먼저 해당 연도/월이 TIME_MONTH에 이미 있는지 조회
    $sql = "SELECT month_id FROM time_month WHERE year = :y AND month = :m";
    $stmt = oci_parse($conn, $sql);
    oci_bind_by_name($stmt, ':y', $y);     // 바인딩 :y → $y
    oci_bind_by_name($stmt, ':m', $m);     // 바인딩 :m → $m
    oci_execute($stmt);
    $row = oci_fetch_assoc($stmt);
    if ($row) return $row['MONTH_ID'];     // 있으면 그 month_id 사용

    // 2) 없으면 새로 INSERT 한 뒤, 생성된 month_id를 받아서 사용
    $sql = "INSERT INTO time_month (year, month, month_label) VALUES (:y, :m, :lbl) RETURNING month_id INTO :nid";
    $stmt = oci_parse($conn, $sql);
    oci_bind_by_name($stmt, ':y', $y);
    oci_bind_by_name($stmt, ':m', $m);

    // month_label은 'YYYY-MM' 형식으로 생성
    $lbl = sprintf("%04d-%02d", $y, $m);
    oci_bind_by_name($stmt, ':lbl', $lbl);

    // RETURNING절로 되돌려 받을 month_id 변수 준비
    $nid = 0;
    oci_bind_by_name($stmt, ':nid', $nid, -1, OCI_B_INT);

    // INSERT 실행 후, $nid에 새 month_id가 들어감
    oci_execute($stmt);
    return $nid;
}
```
- 이 함수의 역할
    - "2024-03" 이런 문자열이 들어오면 TIME_MONTH 테이블에서 맞는 month_id를 찾아서 돌려주고, 없으면 새로 INSERT해서 만든 다음 그 id를 돌려준다"
    - 즉, 판매 데이터 INSERT/UPDATE 할 때 month_id를 자동으로 맞춰주는 도우미
- oci_parse() : SQL을 실제로 실행하기 위한 준비 작업을 하는 함수
    - $stmt = oci_parse($conn, $sql); -> $stmt = Oracle이 실행할 수 있는 "준비된 실행 계획"
- oci_bind_by_name() : SQL 안의 변수에 PHP 변수를 연결(바인딩) 해 주는 역할을 하는 함수
- oci_execute() : 준비해 둔 SQL문장을 실제로 Oracle DB에서 실행시키는 함수("SQL을 실제로 실행해!)
- if ($row) : $row가 비어있지 않으면 true
- sprint() : 문자열을 원하는 형식대로 만들어 주는 함수
- RETURNING month_id INTO :nid : INSERT하면서 자동 생성된 month_id를 :nid 변수로 되돌려받기

- (6) prediction 테이블에 MERGE(upset)
```
    // D. DB 저장 (MERGE)
    $mergeSql = "
        MERGE INTO prediction p
        USING dual ON (p.product_id = :pid AND p.store_id = :sid AND p.month_id = :mid AND p.target = 'revenue')
        WHEN MATCHED THEN
            UPDATE SET p.predicted_value = :val, p.generated_at = SYSDATE
        WHEN NOT MATCHED THEN
            INSERT (store_id, product_id, month_id, target, predicted_value, generated_at)
            VALUES (:sid, :pid, :mid, 'revenue', :val, SYSDATE)
    ";
    // * 주의: MERGE 조건(ON)에 store_id를 추가해야 정확하게 매칭됨

    $mergeStmt = oci_parse($connect, $mergeSql);

    $result = [];
    foreach ($grouped as $key => $data) {
        $avg = round($data['total'] / 3); // 3개월 평균
        
        $trend = ($avg >= $data['last_rev']) ? 'up' : 'down';
        $diff  = abs($avg - $data['last_rev']);

        // 바인딩
        oci_bind_by_name($mergeStmt, ':pid', $data['product_id']); // 표준 ID
        oci_bind_by_name($mergeStmt, ':mid', $targetMonthId);
        oci_bind_by_name($mergeStmt, ':val', $avg);
        oci_bind_by_name($mergeStmt, ':sid', $data['store_id']); // 매장 ID
        
        if(!oci_execute($mergeStmt, OCI_NO_AUTO_COMMIT)) {
             $e = oci_error($mergeStmt);
             error_log("Merge Error: " . $e['message']);
        }

        $result[] = [
            'name'              => $data['name'],
            'predicted_revenue' => $avg,
            'last_revenue'      => $data['last_rev'],
            'trend'             => $trend,
            'diff'              => $diff
        ];
    }
    
    oci_commit($connect);
    oci_free_statement($mergeStmt);
```
- MERGE란 : "이미 있으면 UPDATE, 없으면 INSERT 해라"를 한 번에 하는 Oracle 문법
    - 조건: (product_id, store_id, month_id, target='revenue') 가 같으면 같은 행으로 본다.
    - OCI_NO_AUTO_COMMIT : 자동 커밋하지 말고, 마지막에 oci_commit($connect)로 한 번에 커밋
- foreach() : 배열이나 객체의 각 요소를 하나씩 자동으로 반복해서 꺼내주는 문법
- $avg = round($data['total'] / 3): 3개월 단순 이동평균
- $trend = ($avg >= $data['last_rev']) ? 'up' : 'down'; : 예측값이 최근 매출보다 크면 'up' 아니면 'down'
- $diff  = abs($avg - $data['last_rev']); : 둘이 차이(절대값)

                ORDER BY tm.year DESC, tm.month DESC, s.sale_id DESC";

        oci_execute($stmt);

        $rows = [];
        while ($r = oci_fetch_assoc($stmt)) {
            // 각 판매행을 JSON 객체 하나로 만들어 배열에 추가
            $rows[] = [
                'id'         => $r['SALE_ID'],             // 판매 ID
                'date'       => $r['MONTH_LABEL'],         // 'YYYY-MM' 형식 월 라벨
                'store'      => $r['STORE_NAME'],          // 매장명
                'item'       => $r['MERCHANT_PRODUCT_NAME'], // 매장별 상품명
                'product_id' => $r['MERCHANT_PRODUCT_ID'], // 매장별 상품 ID
                'qty'        => $r['QTY'],                 // 수량
                'price'      => $r['UNIT_PRICE'],          // 단가
                'revenue'    => $r['REVENUE']              // 매출(수량*단가)
            ];
        }
        echo json_encode($rows);
    }
}
```
- 판매 목록을 최신 달 -> 오래된 달 순서로 정렬해서 가져옴
- 각 행을 JSON 객체로 만들어 배열에 담고 json_encode로 응답

```
    else {
