# 벡엔드 구축

1. 맨 위 - 공통 설정
```
<?php
header('Content-Type: application/json; charset=utf-8');
include 'db_conn.php'; // DB 접속 정보 ($connect)

$method = $_SERVER['REQUEST_METHOD'];
$action = $_GET['action'] ?? '';
```
- header('Content-Type: application/json; charset=utf-8'); 
    - "이 PHP는 JSON을 반환하는 API야"라고 브라우저에게 알려줌
    - 한글 까지지 말라고 charset=utf-8 도 같이 설정
- include 'db_conn.php';
    - 아까 만든 DB연결 파일 불러오기
    - 이 파일 안에서 $connect 가 Oracle에 연결된 상태로 사용 가능
- $method = $_SERVER['REQUEST_METHOD'];
    - 지금 요청이 GET인지 POST인지 확인
    - 프론트에서 fetch('sales_api.php') 하면 보통 GET
    - fetch(..., {method:'POST'}) 하면 POST
- $action = $_GET['action'] ?? '';
    - URL에 ?action=products 처럼 붙어온 값 읽기
    - 없으면 빈 문자열 ('') → 어떤 기능을 할지 분기하는 용도


2. 보조 함수 - 날짜 -> TIME_MONTH 키 만들기
```
function getMonthId($conn, $dateStr) {
    if(!$dateStr) return null;
    $parts = explode('-', $dateStr); 
    $y = (int)$parts[0]; $m = (int)$parts[1];

    // 1. 조회
    $sql = "SELECT month_id FROM time_month WHERE year = :y AND month = :m";
    $stmt = oci_parse($conn, $sql);
    oci_bind_by_name($stmt, ':y', $y);
    oci_bind_by_name($stmt, ':m', $m);
    oci_execute($stmt);
    $row = oci_fetch_assoc($stmt);
    if ($row) return $row['MONTH_ID'];

    // 2. 없으면 생성
    $sql = "INSERT INTO time_month (year, month, month_label) VALUES (:y, :m, :lbl) RETURNING month_id INTO :nid";
    $stmt = oci_parse($conn, $sql);
    oci_bind_by_name($stmt, ':y', $y);
    oci_bind_by_name($stmt, ':m', $m);
    $lbl = sprintf("%04d-%02d", $y, $m);
    oci_bind_by_name($stmt, ':lbl', $lbl);
    
    $nid = 0;
    oci_bind_by_name($stmt, ':nid', $nid, -1, OCI_B_INT);
    oci_execute($stmt);
    return $nid;
}
```
- 이 함수의 역할: "2024-03" 같은 문자열을 넣으면
    - time_month 테이블에서 해당 연/월의 month_id를 찾아서 돌려줌
    - 없으면 새로 INSERT 하고, 새로 만들어진 month_id를 돌려줌.
- explode('-', $dateStr);
    - "2024-03" → ["2024", "03"]
    - y = 2024, m = 3
- 먼저 SELECT month_id ... WHERE year = :y AND month = :m 로 있는지 확인
    - 있으면 그 MONTH_ID를 바로 리턴해서 끝
- 없으면 INSERT INTO time_month ... RETURNING month_id INTO :nid
    - 새로운 row를 넣고, 오라클에서 생성된 month_id 값을 :nid로 돌려받음
    - 그걸 return
- 나중에 판매 데이터 INSERT/UPDATE 할 때 월 단위 키(month_id)를 자동으로 맞춰주는 역할

- action=products → 상품 목록 조회
```
if ($action === 'products') {
    $sql = "SELECT mp.merchant_product_id, s.store_name, mp.merchant_product_name 
            FROM merchant_product mp
            JOIN store s ON mp.store_id = s.store_id
            ORDER BY s.store_name, mp.merchant_product_name";
    $stmt = oci_parse($connect, $sql);
    oci_execute($stmt);
    
    $list = [];
    while($r = oci_fetch_assoc($stmt)){
        $list[] = [
            'id' => $r['MERCHANT_PRODUCT_ID'], 
            'store' => $r['STORE_NAME'], 
            'name' => $r['MERCHANT_PRODUCT_NAME']
        ];
    }
    echo json_encode($list);
}
```
- merchant_product + store JOIN 해서
    - 상품 id
    - 매장 이름
    - 상품 이름
    가져오기
- while(oci_fetch_assoc(...)) 로 한 줄씩 읽어서
    - PHP 배열 $list[] 에 [id, store, name] 형태로 담기
- 마지막에 echo json_encode($list);
    - JSON 배열로 프론트에 전달
    - 프론트에서는 이걸 드롭다운(상품 선택)이랑 매장 선택에 사용

- action=mart_recommendation → 대형마트에 없는 독점상품
```
elseif ($action === 'mart_recommendation') {
    $storeName = $_GET['store'] ?? '';
    if (empty($storeName)) { echo json_encode([]); exit; }

    $sql = "
        SELECT 
            mp.MERCHANT_PRODUCT_NAME as name,
            p.STANDARD_CATEGORY      as category
        FROM MERCHANT_PRODUCT mp
        JOIN PRODUCT p ON mp.PRODUCT_ID = p.PRODUCT_ID
        JOIN STORE s ON mp.STORE_ID = s.STORE_ID
        WHERE s.STORE_NAME = :sname
          AND NOT EXISTS (
              SELECT 1 
              FROM PRODUCT_LM_MAP map 
              WHERE map.PRODUCT_ID = mp.PRODUCT_ID
          )
        ORDER BY p.STANDARD_CATEGORY, mp.MERCHANT_PRODUCT_NAME
    ";
    
    $stmt = oci_parse($connect, $sql);
    oci_bind_by_name($stmt, ':sname', $storeName);
    oci_execute($stmt);

    $rows = [];
    while ($r = oci_fetch_assoc($stmt)) {
        $rows[] = ['name' => $r['NAME'], 'category' => $r['CATEGORY']];
    }
    echo json_encode($rows);
}
```
- 선택된 매장에 대해 대형마트(LARGE_MART_PRODUCT)와 매핑되지 않은 상품을 찾아서 
-> "우리 매장만 파는 독점 상품" 리스트로 돌려줌
- PRODUCT_LM_MAP에 없는 상품만 골라내는 NOT EXISTS 조건이 핵심
