# DB 홈페이지에 연결하기

```
<?php
$db_host = "203.249.87.57";
$db_port = "1521";
$db_sid  = "orcl";
$db_user = "DB2025_501_1";
$db_pass = "DB2025_501_1";
```
$db_host: DB서버의 IP주소
$db_port: Oracle이 사용하는 포트번호
$db_sid: Oracle DB의 SID
$db_user: DB 접속 계정 이름
$db_pass: DB 접속 비밀번호


```
$db_str = "(DESCRIPTION=(ADDRESS=(PROTOCOL=TCP)(HOST=$db_host)(PORT=$db_port))(CONNECT_DATA=(SID=$db_sid)))";
```
Oracle 접속 문자열 만들기


```
$connect = oci_connect($db_user, $db_pass, $db_str, 'AL32UTF8');
```
실제 DB 접속
'AL32UTF8': 문자 인코딩(UTF8로 설정). 한글깨짐 방지
성공하면 $connect변수에 연결객체(conn)이 들어있음


```
if (!$connect) {
    $e = oci_error();
    die("DB Connection Failed: " . $e['message']);
}
?>
```
연결 실패했을 때 에러 출력
$connect가 false면 실패
oci_error()는 오라클에서 준 에러 메시지 가져오기
die()로 프로그램 실행을 멈추고 에러 메시지 출력
